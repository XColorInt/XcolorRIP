프린터와 지역을 알려 주세요. 직접 또는 현지 딜러를 통해 트라이얼 키를 받으실 수 있습니다.

체험과 구매 순서

네 단계입니다. 소프트웨어 패키지는 트라이얼 키와 정식 키가 같고, 키만 다릅니다.

1. 확인

영상과 브로슈어를 보시고, 프린터 모델을 이메일로 보내 주세요. 지원되는 프린터인지 확인해 드립니다.

2. 키 받기

트라이얼 키: 50 USD + 배송비. 또는 현지 딜러에게 문의하거나 정식 키를 구매하세요. 가격과 조건은 지역과 딜러에 따라 다릅니다.

3. 설치

GitHub 릴리스 페이지에서 패키지(zip)를 받아 전부 풀고, Windows 64비트 PC에서 setup.exe 를 실행합니다.

4. 전환

마음에 드시면 정식 라이선스 대금을 내시고, 같은 키를 원격으로 업그레이드해 드립니다. 새 하드웨어는 필요 없습니다.
