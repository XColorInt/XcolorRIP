빠른 RIP. 하이파이 컬러. 쉬운 화이트 잉크.

XColorRIP x64는 Epson 프린터와 중국 보드 DTF·UV·롤 프린터를 위한 생산용 RIP 소프트웨어입니다. 64비트 속도, EPS·PSD·PNG·TIF에서 바로 만드는 화이트 잉크, 화이트가 포함된 6색·8색 하이파이 컬러, 기본 내장 컬러 관리를 제공합니다.

체험 신청 딜러 문의
XColorRIP x64 기능 화이트 잉크 하이파이 컬러 컬러 관리 영상 지원 프린터 자료 다운로드
64비트 + 멀티스레드PC 메모리를 모두 사용합니다. 망점 처리와 이미지 처리가 동시에 실행됩니다.
6C / 8C + 화이트DTF·UV 프린터용 화이트 모드가 있는 하이파이 컬러.
CMS 기본 포함Density Read와 컬러 관리가 일반 버전에 포함되어 있습니다.

기능

속도부터 색상까지, 생산 현장에서 필요한 XColorRIP의 기능입니다.

1. 빠른 리핑 속도

예전 32비트 프로그램은 PC 메모리가 아무리 많아도 최대 2GB까지만 사용할 수 있었습니다. XColorRIP은 네이티브 64비트 프로그램이라 OS가 쓰지 않는 메모리를 모두 활용할 수 있습니다.

네이티브 64비트

PC의 모든 메모리를 RIP이 사용합니다. 큰 파일과 긴 현수막도 메모리에서 처리합니다.

멀티스레드

망점(스크리닝) 처리와 이미지 처리를 여러 스레드로 동시에 실행해 리핑 속도를 크게 높였습니다.

이미지 확대 모드

품질을 아주 조금(거의 눈에 띄지 않는 정도) 줄이는 대신 속도를 더 높이는 선택 기능입니다. 600×5000 현수막(SC4180H1)에서 3.6배 빨랐습니다.*

*표준 모드 3분 5초, 이미지 확대 모드 51초. 결과는 프린터와 파일에 따라 다릅니다.

2. 쉬운 화이트 잉크

PSD·PNG 투명도, TIF 마스크 채널, EPS 파일을 지원합니다.

  • EPS: 벡터로 디자인한 그대로 화이트 잉크 영역이 추출됩니다. 별도 이미지로 내보내고 마스크를 만들 필요가 없습니다.
  • PSD / PNG: 투명한 부분이 자동으로 화이트가 됩니다.
  • TIF: 마스크 채널로 세밀하게 제어할 수 있습니다.
  • 지원되는 소형 Epson 프린터에서 화이트와 컬러를 한 번에 출력합니다(Epson XP15010, L805 / L1800 시리즈에서 확인).

3. 화이트까지 되는 6색·8색 하이파이

DTF와 UV 인쇄는 하이파이 컬러로 가고 있습니다. XColorRIP은 6색(CMYK + 오렌지 + 그린)과 8색(CMYK + 오렌지 + 그린 + 레드 + 블루), 그리고 화이트 모드를 DTF·UV 프린터에서 지원합니다.

  • 6C 하이파이 컬러: CMYKOrGr
  • 8C 하이파이 컬러: CMYKOrGrRedBlue
  • DTF·UV용 화이트 모드를 위에 추가
  • RGB 사진은 하이파이 변환 전에 올바른 컬러 관리 단계를 거치므로 어두운 부분의 깊이가 유지됩니다

4. 컬러 관리 기본 포함

Density Read 프로그램이 일반 버전에 포함되어 있어서, 농도 커브, 잉크 리밋, ICC 프로파일까지 CMS 작업을 별도 구매 없이 모두 할 수 있습니다.
