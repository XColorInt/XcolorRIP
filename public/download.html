How to try and buy

Four steps. The software package is the same for a trial key and a full license key; only the key is different.

1. Check

Watch the videos, read the brochure, and email us your printer model. We confirm that your printer is supported.

2. Get a key

Trial key: 50 USD plus shipping. Or ask a local dealer, or buy a full license key. Prices and terms vary by region and dealer.

3. Install

Download the package (zip) from our GitHub releases page, extract all of it, and run setup.exe on a Windows 64-bit PC.

4. Upgrade

If you like it, pay for the full license and we upgrade the same key remotely. No new hardware needed.
